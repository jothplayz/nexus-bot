Nexus Bot — Privacy Policy

Last updated: November 11, 2026

Nexus Bot is a personal application used only by its owner. It is not available to other users.

What data it accesses

When authorized by the owner, Nexus Bot uses the Google Calendar API to read, create, update and delete events on the owner's own calendars.

How data is used

Calendar data is used only to carry out the owner's requests. It is not sold, shared with third parties, used for advertising, or used to train AI models.

Storage

OAuth tokens are stored encrypted on the owner's private server. Calendar data is not kept beyond what is needed to answer a request.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Nexus Bot's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions: open an issue at github.com/jothplayz/nexus-bot.
